# Instrucciones para Claude

## Commits

- **Nunca hagas commits** (ni `git commit`, ni `git commit --amend`, ni `git push`). Los commits los hace siempre el usuario.
- Cuando termines de dejar lista una tarea, no ejecutes nada en git: al final de tu respuesta entrega un **mensaje de commit sugerido** para que el usuario lo copie y lo use.

### Formato del mensaje sugerido

- En español, en minúsculas y en una sola línea corta, siguiendo el estilo del historial (ej. `mejoras SEO`, `fix: scroll de modales`).
- Usa el prefijo `fix:` cuando sea una corrección de error.
- Si la tarea toca varias cosas, añade un cuerpo breve con viñetas debajo de la línea de resumen.
- Entrégalo dentro de un bloque de código para que sea fácil de copiar.

## Idioma

- Responde siempre en español.
